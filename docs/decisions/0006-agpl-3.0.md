# 0006 — Licence: AGPL-3.0

Status: accepted (2026-07)

## Context

CiviCRM and its Gift Aid / GDPR extensions are AGPL-3.0. Adopting the same
licence legitimately enables porting the hardest UK-specific engineering —
the HMRC GovTalk/IRmark submission logic — instead of a clean-room
reimplementation (research.md §B4.4, §B8).

## Decision

The whole codebase is AGPL-3.0 (`LICENSE` at repo root). Accepted
implication: the network clause means anyone we host the software for may
request corresponding source — the business model is open-core / paid
hosting + support, not proprietary SaaS.

## Consequences

- Porting from CiviCRM's AGPL extensions is allowed and encouraged where
  it saves risk (GovTalk/IRmark especially).
- Per-client extensions (ADR 0010) that we distribute to a client's
  deployed instance are also AGPL — price customisation as a service, not
  as proprietary code.
- Keep dependency licences compatible (no GPL-incompatible libs in the
  distributed artefact).
